项目功能

实时关键点检测

实时检测手部21个三维关键点，精准跟踪手部运动

15+种手势识别

支持数字0-5、拳头、张开、OK、点赞、摇滚等多种手势（但是不太灵敏，有些手势还是无法识别，后续还需要继续改进）

左右手区分

自动识别左右手并显示置信度，准确率超过95%

动态手势检测

支持挥手等动态手势识别，响应迅速

手势历史记录

自动记录最近识别的手势，方便查看和分析

一键录屏功能

内置录屏功能，一键保存演示视频

技术方案与实现思路

本项目使用Google开发的MediaPipe Hands框架实现手部关键点检测，这是一个轻量级、高性能的计算机视觉解决方案。

核心技术栈

Python 3.9+ MediaPipe 0.10.9 OpenCV 4.8.1 NumPy

实现步骤

  1. 使用OpenCV从摄像头捕获实时视频流
  2. 将每一帧图像传入MediaPipe预训练模型进行处理
  3. 获取手部21个三维关键点坐标和左右手信息
  4. 通过分析关键点的相对位置关系，判断手指是否伸出
  5. 基于几何特征识别不同的静态手势
  6. 通过跟踪关键点的运动轨迹识别动态手势
  7. 在图像上绘制关键点、连接线和识别结果
  8. 实现一键录屏功能，保存演示视频

项目采用模块化设计，代码结构清晰，易于扩展和维护。所有功能都在普通CPU上实时运行，不需要GPU支持。
